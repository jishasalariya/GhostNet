# GhostNet

A lightweight web security analysis tool for evaluating URLs through crawling, network checks, trust scoring, and AI-assisted analysis.

## Features

- URL and domain security analysis
- Safe crawling with boundary validation
- Protection against internal network requests
- Trust-score evaluation
- AI-assisted analysis with Google Gemini
- Supabase-backed data handling
- FastAPI backend with React frontend

## Tech Stack

`Python` · `FastAPI` · `React` · `Vite` · `Supabase` · `Google Gemini`

## Setup

```bash
git clone <repository-url>
cd GhostNet
pip install -r requirements.txt
```
